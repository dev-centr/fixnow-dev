Pressure-driven issue tracking for high-value, stagnated features.

== About The Project

FixNow combines Gemini assessments with public countdown badges so critical ignored issues stay visible.

=== Features

* *AI-rated technical value* — scores issues from 0–100 for complexity and impact.
* *Dynamic image proxy* — SVG countdown badges via `/api/timer/{id}` for READMEs and chat.
* *Resolution verification* — AI audit of closures (implemented vs ignored vs alternate).
* *SolidStart UI* — SolidStart + Tailwind CSS v4.

== Installation

. Clone and install
+
[source,bash]
----
corepack enable
pnpm install
----

. Create `.env`
+
[source,env]
----
GOOGLE_GENERATIVE_AI_API_KEY=YOUR_API_KEY
GITHUB_TOKEN=YOUR_GH_TOKEN
----

link:#readme-top[back to top]
